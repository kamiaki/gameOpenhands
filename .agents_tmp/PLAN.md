# 1. OBJECTIVE
创建一个基于 Phaser.js 的 HTML5 游戏项目，能够通过浏览器运行。

# 2. CONTEXT SUMMARY
- 使用 Phaser.js (v3.60+) 游戏框架
- 项目位于 /workspace/project/gameOpenhands
- 需要包含完整的 HTML 入口、游戏配置、至少一个游戏场景

# 3. APPROACH OVERVIEW
1. 使用 npm 初始化项目，安装 Phaser.js
2. 创建 HTML 入口文件 (index.html)
3. 创建游戏主入口 JavaScript 文件
4. 实现核心游戏场景（启动场景 + 主游戏场景）
5. 启动开发服务器验证

# 4. IMPLEMENTATION STEPS
- [x] 初始化 npm 项目并安装 Phaser.js
- [ ] 创建 index.html 入口文件
- [ ] 创建游戏主配置 (js/main.js)
- [ ] 创建启动场景 (js/scenes/BootScene.js)
- [ ] 创建主游戏场景 (js/scenes/GameScene.js)
- [ ] 启动服务器并验证

# 5. TESTING AND VALIDATION
- 通过 http://localhost:8000 访问游戏页面
- 确认 Phaser.js 成功加载并渲染游戏画面
